# Ядро бизнес-логики (расчёт скидки)

discount.py — функция calculate_partner_discount: по суммарному объёму закупок
партнёра возвращает его процент скидки. test_discount.py — тесты к ней.

```bash
python3 -m unittest -v
```

Пороги взяты из ТЗ: до 10 000 — 0%, 10 000–49 999 — 5%, 50 000–299 999 — 10%,
от 300 000 — 15%. Условия идут по возрастанию, поэтому верхнюю границу диапазона
писать не нужно: до проверки `total_quantity < 50000` доходят только значения
от 10 000.

Тестов восемь: пять пограничных значений из задания и ещё 0, 299999 и 1000000 —
они закрывают верхнюю границу диапазона 10% и ветку 15%. Покрытие discount.py —
100% по строкам и по ветвям:

```bash
python3 -m pip install coverage
python3 -m coverage run --branch --source=discount -m unittest -q
python3 -m coverage report -m
```
