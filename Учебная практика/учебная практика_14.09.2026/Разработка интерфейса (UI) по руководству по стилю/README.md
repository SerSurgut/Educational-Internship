# Разработка интерфейса (UI) по руководству по стилю

main_window.py — главное окно CRM со списком партнёров и их скидок на Tkinter.
В resources/ лежат логотип и иконка приложения.

```bash
python3 main_window.py
```

Оформление взято со Screenshot_2: белый фон, тонкие серые рамки, чёрный текст
шрифтом Segoe UI, название и скидка крупнее остальных строк. Кнопок на макете
нет, поэтому на форме их тоже нет. Нужен Python с Tk 8.6 или новее: системный
Python macOS с Tk 8.5 не открывает PNG. Segoe UI на macOS нет, Tkinter
подставляет системный шрифт, а iconphoto меняет значок в Dock.

Рамка карточки задана через highlightbackground: relief="solid" рисует рамку
только чёрной. Первому столбцу grid дан вес, чтобы скидка прижималась вправо.

В таблице partners нет типа и директора из макета: тип уже входит в название
(ООО, ИП, ТК), а вместо директора выводится e-mail. Партнёры пока заданы в коде
с теми же ключами, что у get_partner_with_discount, — база подключится
в следующем задании. Пустой телефон или рейтинг показан прочерком, а не None.

Картинки хранятся в переменных icon и logo, пока открыто окно: Tkinter
не держит свою ссылку на PhotoImage, и без неё логотип пропал бы с формы.
