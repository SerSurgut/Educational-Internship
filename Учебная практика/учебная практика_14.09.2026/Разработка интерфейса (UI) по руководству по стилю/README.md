# Разработка интерфейса (UI) по руководству по стилю

main_window.py — главное окно CRM со списком партнёров и их скидок на Tkinter.
В resources/ лежат логотип и иконка приложения. partners_update.sql добавляет
в базу тип партнёра и ФИО директора, которые нужны карточке.

```bash
psql -d partners_db -f partners_update.sql
python3 main_window.py
```

Карточка повторяет Screenshot_2: «Тип | Наименование», ФИО директора, телефон
в виде +7 999 111 22 33, рейтинг и скидка справа; белый фон, серые рамки,
шрифт Segoe UI. Нужен Tk 8.6 или новее: Tk 8.5 из macOS не открывает PNG.

В схеме первой практики не было ни типа, ни директора. Тип вынесен
в справочник partner_types, как товары в products, — иначе одно и то же
«ООО» повторялось бы текстом у каждого партнёра. Скрипт отделяет тип от
названия и заполняет директоров по ИНН; в исходном файле ФИО не было,
они придуманы. Партнёры в форме пока заданы в коде в том виде, в каком
их отдаёт база, — к базе форма подключится в следующем задании.

Рамка карточки задана через highlightbackground: relief="solid" рисует рамку
только чёрной. Картинки хранятся в переменных icon и logo, пока открыто окно:
Tkinter не держит свою ссылку на PhotoImage, и без неё логотип пропал бы.
