# Проектирование многооконной архитектуры и навигации

main_window.py — главное окно MainWindow со списком партнёров,
partner_edit_window.py — окно PartnerEditWindow для добавления и
редактирования партнёра, style.py — шрифт и цвета обоих окон.
partner_service.py и discount.py взяты из прошлой практики. База
разворачивается по README в корне репозитория, включая partners_update.sql.

```bash
python3 -m pip install psycopg2-binary
python3 main_window.py
```

«Добавить партнера» прячет главное окно через withdraw() и открывает
карточку, «Назад» закрывает карточку и возвращает главное окно через
deiconify(). Главное окно не уничтожается, поэтому список и прокрутка
остаются на месте, а партнёры не загружаются из базы заново.

Карточка сделана через Toplevel, а не вторым tk.Tk(): второй Tk — отдельный
интерпретатор, и иконка с картинками первого окна в нём не работают. Крестик
карточки вызывает тот же go_back, что и «Назад», — иначе карточка закрылась
бы, а спрятанное главное окно осталось бы невидимым вместе с программой.

Карточка пока открывается только кнопкой «Добавить партнера», поэтому
в заголовке у неё «[Добавление]». Шрифт и цвета вынесены в style.py, потому
что main_window.py импортирует карточку и обратный импорт был бы циклическим.
