# Разработка формы добавления/редактирования партнера

partner_edit_window.py — форма PartnerEditWindow с полями партнёра,
main_window.py — главное окно, из которого она открывается. style.py,
partner_service.py и discount.py взяты из прошлого задания, в
partner_service.py добавлена загрузка типов партнёров.
partners_form_update.sql дополняет базу под поля формы.

```bash
psql -d partners_db -f partners_form_update.sql
python3 main_window.py
```

Типы в выпадающем списке берутся из справочника partner_types, а не
записаны в коде, поэтому выбрать можно только тип, который есть в базе.
Combobox в режиме readonly: свой тип в нём не напечатать, только выбрать.
В справочнике не было ЗАО, а в partners — столбца для адреса, их добавляет
partners_form_update.sql.

Рейтинг вводится в Spinbox с шагом 1 от 0 до 10: стрелки сразу показывают,
что нужно целое число, а верхняя граница та же, что в CHECK столбца rating.

У tk.Entry нет плейсхолдера, поэтому подсказка у телефона и email — серый
текст внутри поля. Он стирается, когда пользователь переходит в поле,
и возвращается, если поле осталось пустым. Телефон в подсказке записан
так же, как в карточках главного окна.
