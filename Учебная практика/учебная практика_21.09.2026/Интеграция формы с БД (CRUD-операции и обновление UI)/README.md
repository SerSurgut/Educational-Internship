# Интеграция формы с БД (CRUD-операции и обновление UI)

main_window.py и partner_edit_window.py — окна из прошлого задания, теперь
карточка партнёра сохраняет данные в базу. Запросы INSERT и UPDATE лежат
в partner_service.py, partners_crud_update.sql подготавливает под них базу.

```bash
psql -d partners_db -f partners_crud_update.sql
python3 main_window.py
```

Карточка на редактирование открывается двойным кликом по партнёру. Данные
в неё читаются из базы в момент открытия, а не берутся из списка, поэтому
в форме всегда актуальная запись. После сохранения список строится заново.

Тип хранится как ссылка на partner_types: перед сохранением код находит id
выбранного типа в справочнике, и если типа нет или UPDATE не нашёл партнёра,
сохранение прерывается. Всё идёт в одной транзакции (`with connection`).

Пока в поле телефона или email стоит серая подсказка, поле считается пустым,
и в базу уходит NULL, а не текст подсказки. Пустые поля тоже сохраняются как
NULL: email уникален, и две пустые строки не дали бы сохранить второго
партнёра без почты. Пробелы из телефона убираются, чтобы номер хранился так
же, как у остальных партнёров.

В форме нет поля ИНН, поэтому partners_crud_update.sql снимает с inn
NOT NULL, уникальность остаётся. Рейтинг в форме целый, а в базе был
DECIMAL(4,2) — столбец переведён в INT с округлением старых значений.
