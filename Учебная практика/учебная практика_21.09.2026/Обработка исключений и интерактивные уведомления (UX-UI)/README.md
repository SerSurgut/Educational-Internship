# Обработка исключений и интерактивные уведомления (UX/UI)

Окна из прошлого задания, теперь с проверкой ввода и сообщениями
пользователю. Проверки полей — в partner_edit_window.py, запуск прежний:

```bash
python3 main_window.py
```

Перед сохранением форма проверяет наименование, рейтинг и email. Каждая
проверка при ошибке бросает ValueError с текстом для пользователя, а `save`
ловит его в `try...except` и показывает окно ошибки. Так текст ошибки
лежит рядом с проверкой, а сохранение в базу не начинается.

Рейтинг проверяется до 10, хотя задание требует только «от 0»: в базе
на столбце стоит CHECK до 10, и без этой проверки число 11 дошло бы до
базы и вернулось непонятной ошибкой СУБД.

Ошибки базы ловятся отдельно: повтор email (IntegrityError) — с просьбой
указать другой адрес, остальные ошибки psycopg2 — как недоступная база.
Если база не отвечает уже при запуске, приложение показывает ту же ошибку
и не открывает пустое главное окно.

Предупреждение о потере данных появляется, только если поля отличаются
от того, что было при открытии карточки. Крестик окна работает так же,
как «Назад», иначе изменения терялись бы без вопроса.
