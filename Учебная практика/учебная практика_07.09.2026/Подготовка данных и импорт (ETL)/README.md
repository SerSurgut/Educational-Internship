# Подготовка данных и импорт

etl.sql загружает данные из data/import_partners.csv и data/import_sales.txt.

```bash
psql -d partners_db -f etl.sql
```

Запускать из этой папки — скрипт читает файлы по относительному пути.
Перед этим должна быть создана структура через schema.sql.

Сначала данные попадают во временные таблицы stg_partners и stg_sales, где
все поля text. Если грузить сразу в рабочие таблицы, первая же строка с
неверной датой оборвёт импорт. После очистки данные переносятся дальше.

## Что чистим

- лишние пробелы вокруг названий — trim
- пустой телефон и пустой рейтинг — nullif, записываем NULL
- телефоны в разном виде — оставляем только цифры и приводим к +7XXXXXXXXXX
- e-mail в разном регистре — lower
- файл отгрузок оказался с табуляцией вместо запятой — DELIMITER E'\t'
- даты в двух форматах, 2026-03-01 и 15.03.2026 — распознаём оба через CASE
- название товара повторяется — уникальные переносим в products
- кавычки в названиях товаров — QUOTE E'\b', иначе COPY принял бы их за
  обрамление поля и удалил

Отгрузка 104 не загружается: в ней партнёр с id 4, которого нет в справочнике.
В конце скрипт выводит количество строк по таблицам и эту строку с причиной.
