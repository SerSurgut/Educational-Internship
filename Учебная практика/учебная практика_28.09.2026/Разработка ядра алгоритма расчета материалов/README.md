# Ядро алгоритма расчёта материалов

material_calculator.py — функция calculate_material_quantity: по типу продукции,
типу материала, количеству изделий и двум параметрам изделия возвращает,
сколько материала нужно с учётом брака. reference_mock.py — справочники
коэффициентов типов продукции и процентов брака материалов.

```bash
python3 material_calculator.py
```

Справочников типов продукции и материалов в нашей базе нет, поэтому они
сделаны мок-объектами — словарями «id → значение». Значения взяты из данных
демоэкзамена: типы продукции 1–4 (ламинат 2.35, массивная доска 5.15,
паркетная доска 4.34, пробковое покрытие 1.5), типы материалов 1–5 с браком
0.10%, 0.95%, 0.28%, 0.55% и 0.34%. Обращение к справочнику вынесено
в get_product_type_coefficient и get_material_defect_percent: если позже
справочники появятся в базе, поменяются только эти две функции.

Несуществующий id словарь возвращает как None через get, поэтому метод
не падает с KeyError, а возвращает -1. Количество и оба параметра должны быть
больше нуля: параметры в ТЗ названы положительными, а при нуле расход
получился бы нулевым, что для заказа тоже ошибка. Округление вверх через
math.ceil — материала не может не хватить из-за округления.
