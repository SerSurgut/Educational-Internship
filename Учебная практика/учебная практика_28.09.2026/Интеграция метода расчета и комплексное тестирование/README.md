# Интеграция метода расчета и комплексное тестирование

Приложение CRM для партнеров с калькулятором материалов.
material_calculator.py — метод расчета материалов, reference_mock.py —
справочники коэффициентов типов продукции и процентов брака,
material_calculator_window.py — окно калькулятора. Остальные файлы — окна
и запросы к базе для партнеров. Калькулятор открывается кнопкой «Расчет
материалов» на главном окне:

```bash
python3 main_window.py
```

Калькулятор — отдельное модальное окно: расчет относится к продукции,
а не к партнеру. Результат выводится строкой на форме.

ID типов вводятся обычными полями, а не выпадающим списком, — иначе
несуществующий ID было бы не ввести. Текст из полей переводится в числа
в окне, а все проверки остаются в методе расчета: если текст не читается
как число, в метод уходит None, и он возвращает -1, как и на отрицательный
размер, нулевое количество или неизвестный ID. На -1 форма показывает
ошибку с допустимыми значениями полей, а строка результата сбрасывается.

Справочников типов в базе нет, поэтому они сделаны словарями со значениями
из демоэкзамена; по ним же строится список допустимых ID в сообщении.
