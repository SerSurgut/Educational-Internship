# Разработка интерфейса истории реализации продукции

Окна из прошлого задания и новое окно PartnerHistoryWindow с историей
продаж партнера (partner_history_window.py). Запрос истории —
`get_sales_history` в partner_service.py. Запуск прежний:

```bash
python3 main_window.py
```

Чтобы партнера можно было выбрать перед нажатием «История продаж»,
карточка в списке выделяется одиночным щелчком — фон становится
светло-серым.
Двойной щелчок, как и раньше, открывает карточку на редактирование. Если
партнер не выбран, кнопка показывает предупреждение, а не пустое окно.
После сохранения партнера список перестраивается, и выбор сбрасывается.

В окно передается только partner_id, название партнера и продажи окно
читает из базы само. Чтение идет до создания окна: если база недоступна,
показывается ошибка, и на экране не остается пустого окна истории.

Продажи берутся из таблицы sales (в задании она `sales_history`) с JOIN
к products, новые сверху. Дата выводится в виде ДД.ММ.ГГГГ. Окно истории
модальное, как карточка партнера: главное окно остается под ним.
