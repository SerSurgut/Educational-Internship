# Учебная практика 09.02.07

База данных «Партнёры и отгрузки» на PostgreSQL и приложение к ней на Python.
Задания разложены по практикам: `Учебная практика/учебная практика_<дата>/<название задания>`.

## Как развернуть

```bash
cd "Учебная практика/учебная практика_07.09.2026"

createdb partners_db
psql -d partners_db -f "Написание DDL-скрипта (База данных в коде)/schema.sql"

cd "Подготовка данных и импорт (ETL)"
psql -d partners_db -f etl.sql
cd ..

psql -d partners_db -f "Разработка проверочных SQL-запросов (Эмуляция бэкенда)/queries.sql"
```

ETL запускается из своей папки — он читает файлы из data/ рядом с собой.

После загрузки в базе 3 партнёра, 3 товара и 4 отгрузки. Пятая строка файла
отгрузок не загружается: в ней указан партнёр с id 4, которого нет в справочнике.
