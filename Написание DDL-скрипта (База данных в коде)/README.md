# Написание DDL-скрипта

schema.sql создаёт структуру базы.

```bash
createdb partners_db
psql -d partners_db -f schema.sql
```

Скрипт сначала удаляет таблицы в порядке зависимостей: sales ссылается на
partners и products, поэтому удаляется первой. Дальше создаёт три таблицы
с ключами и ограничениями и индекс на sales(partner_id) — по нему идёт
выборка истории отгрузок партнёра.

Суммы хранятся в DECIMAL(12,2): для денег вещественные типы не подходят
из-за ошибок округления.

Скрипт можно запускать повторно, структура создаётся заново.
