# Проверочные SQL-запросы

queries.sql — три запроса, которые использовало бы приложение.

```bash
psql -d partners_db -f queries.sql
```

Запрос 1 выводит партнёров и количество их доставок через LEFT JOIN и COUNT,
сортировка по названию. LEFT JOIN нужен, чтобы партнёр без отгрузок остался
в списке, а COUNT(s.sale_id) вместо COUNT(*) даёт для него ноль.

Запрос 2 создаёт партнёра и его первую доставку в одной транзакции.
Идентификатор нового партнёра берётся подзапросом по его ИНН, а не через
currval: currval возвращает значение только в той же сессии, где до этого
вызывался nextval, и при запуске одной этой вставки отдельно падает с ошибкой.
Дальше показано, зачем транзакция нужна: во втором блоке вторая вставка
ошибочна, и ROLLBACK отменяет вместе с ней создание партнёра.

Запрос 3 выводит историю отгрузок партнёра за март 2026 — дату, товар,
количество, цену за единицу и сумму, плюс итог за период: 80 штук на 35 500 рублей.
Сумма в базе не хранится, поэтому считается прямо в запросе: quantity * unit_price.
