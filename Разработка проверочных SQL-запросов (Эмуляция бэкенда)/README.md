# Проверочные SQL-запросы

queries.sql — три запроса, которые использовало бы приложение.

```bash
psql -d partners_db -f queries.sql
```

Запрос 1 выводит партнёров и количество их доставок через LEFT JOIN и COUNT,
сортировка по названию. LEFT JOIN нужен, чтобы партнёр без отгрузок остался
в списке, а COUNT(s.sale_id) вместо COUNT(*) даёт для него ноль.

Запрос 2 создаёт партнёра и его первую доставку в одной транзакции.
Идентификатор нового партнёра берётся через currval. Дальше показано, зачем
транзакция нужна: во втором блоке вторая вставка ошибочна, и ROLLBACK
отменяет вместе с ней создание партнёра.

Запрос 3 выводит историю отгрузок партнёра за март 2026 — дату, товар,
количество и сумму, плюс итог за период: 80 штук на 35 500 рублей.
